## 🎯 Inicio Rápido

### Para Desarrolladores Nuevos:
1. Lee **[DOCUMENTACION_TECNICA.md](../DOCUMENTACION_TECNICA.md)** completo
2. Revisa la sección "Arquitectura de Escenas" para entender el flujo
3. Consulta "Sistema de NPCs" para configurar personajes
4. Usa "Solución de Problemas" cuando encuentres errores

### Para Configurar un NPC:
1. Consulta **[DOCUMENTACION_TECNICA.md](../DOCUMENTACION_TECNICA.md)** → Sección 3 (Sistema de NPCs)
2. Sigue el "Checklist de Setup para Nuevo NPC"
3. Si migras desde sistema legacy, consulta **[NPC_BEHAVIOUR_MANAGER.md](NPC_BEHAVIOUR_MANAGER.md)**

### Para Añadir Quests:
1. **[DOCUMENTACION_TECNICA.md](../DOCUMENTACION_TECNICA.md)** → Sección 3.4 (Sistema de Misiones)
2. **[RESUMEN_COMPLETO.md](RESUMEN_COMPLETO.md)** → Ejemplo completo con Eldran
3. **[LOCALIZACION_QUESTS.md](LOCALIZACION_QUESTS.md)** → Añadir textos localizados
